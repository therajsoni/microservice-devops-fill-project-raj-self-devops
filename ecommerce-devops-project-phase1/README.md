# E-Commerce DevOps Project

Production-style microservices starter project for DevOps practice.

## Phase 1
- Next.js frontend
- Node.js services
- PostgreSQL
- MongoDB
- Redis
- Docker Compose
- GitHub
- Jenkins/GitHub Actions
- Kubernetes/Kind
- Helm
- Monitoring and security will be added in later phases.

## Run locally

```bash
docker compose up --build
```

Frontend: http://localhost:3000
API Gateway: http://localhost:4000
